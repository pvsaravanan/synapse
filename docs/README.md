# Synapse documentation

Synapse is a local-first memory layer for AI coding agents. It gives an agent a durable, per-project memory of decisions, pitfalls, fixes and the reasoning behind them. Retrieval is cheap and token-budgeted, so the next session (or a different agent) starts with context instead of rediscovering it.
